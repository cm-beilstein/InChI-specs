InChI Specifications

New features and extensions of InChI, developed in IUPAC-InChI/InChI. Per feature: the technical specification, an explanation for chemists, old-vs-new examples, and how the new InChI is built step by step. The stereo features run behind the option -EnhancedStereochemistry (prefix InChI=1B/); proposed features are open for discussion.

Comments are welcome: per feature, on every molecule and on every explanation section (GitHub account needed).
